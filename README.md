# Security Advisory — Comviva Revenue Plus EL Injection → RCE

Public security advisory for an Expression Language (EL) injection leading to
remote code execution in **Comviva Revenue Plus** (MobiLytix / Customer Value
Management family), discovered during an authorized security assessment.

➡️ **Full advisory: [ADVISORY.md](ADVISORY.md)**

|---|---|

| **Product** | Revenue Plus 3.0.0 |
| **Type** | CWE-917 (EL Injection) → CWE-94 (Code Injection) / RCE |
| **Severity** | Critical |
| **CVSS v3.1** | 9.9 (Critical) — `AV:N/AC:L/PR:L/UI:N/S:C/C:H/I:H/A:H` |
| **Status** | End-of-life, no patch available |
| **CNA** | VulnCheck |
